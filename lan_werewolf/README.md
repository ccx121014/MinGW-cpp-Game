# 局域网联机狼人杀（C++骨架）

这是一个**最小可运行**的局域网联机“狼人杀”骨架：

- 每台电脑运行同一个程序：既能**创建房间（该房间的主机/服务器）**，也能**加入房间（客户端）**
- 房间发现：**UDP 广播**（局域网自动发现）
- 房间通信：**TCP**（主机转发聊天、维护玩家列表）
- 已扩展到**标准版最小流程**：动态配角色（随人数变化）→ 夜晚行动 → 白天发言 → 投票处决 → 胜负判定

## 编译（Dev-C++ / MinGW64）

打开 `main.cpp`，或在命令行执行：

```bat
g++ main.cpp -std=c++17 -O2 -lws2_32 -o lan_werewolf.exe
```

在 Dev-C++ 里如果需要手动加库：把 `ws2_32` 加到链接选项中。

> 如果你用的是较老的 Dev-C++/MinGW（例如 GCC 4.9.x），之前可能会出现 `inet_ntop/inet_pton not declared`。
> 本项目已在代码中改为使用 `InetNtopA/InetPtonA` 兼容该环境；只要确保链接了 `-lws2_32` 即可。

## 使用

1. 在一台电脑上运行，选择 **1) 创建房间**
2. 其他电脑运行，选择 **2) 加入房间**（会广播发现）
3. 进入房间后，输入文字聊天
4. 房主可在控制台输入：
   - `/players` 查看玩家
   - `/start` 开始游戏（发身份并进入夜晚）
   - `/vote` 白天发言阶段强制进入投票（否则 60 秒自动投票）
   - `/leave` 解散并退出房间

> 标准版：**一局最少 5 人**才能开始（房主 `/start` 时会检查）。
>
> 对局中：房间名会显示 `"[对局中]"`，并且**禁止新玩家加入**（需要等对局结束或开新房）。

## 游戏内指令（所有玩家）

- `/help` 查看帮助
- `/menu` 打印“存活玩家编号列表”
- 夜晚/白天需要操作时，**可以直接输入编号**（例如输入 `2`），也可以输入命令：
  - 狼人：`/kill <编号或昵称>`
  - 预言家：`/check <编号或昵称>`
  - 守卫：`/guard <编号或昵称>`
  - 女巫：
    - 解药：`/save yes` 或 `/save no`
    - 毒药：`/poison <编号或昵称>` 或 `/pass`
  - 投票：`/vote <编号或昵称>`
  - 猎人：`/shoot <编号或昵称>` 或 `/pass`

## 常见问题

- **发现不到房间**：请确认在同一局域网，且 Windows 防火墙允许本程序的 UDP(37020) 与 TCP(房间端口) 通信。

## 角色配比（当前代码默认）

狼人数按房间人数动态计算（为了避免 4 人局出现 2 狼导致“基本没法玩”的情况）：

- 4~6 人：1 狼
- 7~9 人：2 狼
- 10~12 人：3 狼
- 其它人数：约为 `人数/4`（至少 1 狼）
