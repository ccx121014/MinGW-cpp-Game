# 斗地主 LAN — 局域网联机斗地主正式发布

## 零服务器、零配置，三步开打

**2026年6月6日** — 一款专为局域网环境打造的斗地主联机游戏今日正式发布。无需公网服务器、无需注册账号、无需安装任何额外依赖，一台电脑创建房间，其余电脑一键搜索加入，三分钟即可开局。

---

## 核心亮点

### 🎮 真正的零门槛联机

传统联机游戏往往需要公网服务器、端口映射、账号注册等繁琐步骤。斗地主 LAN 彻底打破了这一壁垒：

- **UDP 广播自动发现** — 无需手动输入 IP 地址，打开程序即可看到局域网内所有可用房间
- **P2P 架构** — 每台电脑运行同一个程序，创建房间者自动成为主机，无需独立服务器
- **一键编译运行** — 基于 C++ 原生开发，单个源文件，Dev-C++ (MinGW64) 即可编译

### 🃏 完整的斗地主规则

- **54 张标准牌组** — 4 种花色 × 13 张点数 + 大小王
- **叫地主机制** — 1/2/3 分叫分制，无人叫地主自动重新发牌
- **全牌型支持** — 单张、对子、三带一/二、顺子、连对、飞机、四带二、炸弹、火箭
- **智能验证** — 自动检测牌型合法性与大小比较，杜绝作弊

### 🏠 房主也是玩家

与传统的"一人当裁判、其余人游戏"模式不同，斗地主 LAN 中房主同样参与游戏：

- 房主作为玩家 0，拥有完整的手牌和出牌权限
- 房主负责创建房间和启动游戏，游戏开始后与所有玩家平等
- 多线程消息队列架构确保房主既能管理房间又能流畅游戏

## 技术架构

```
┌─────────────────────────────────────────────┐
│              斗地主 LAN 架构                  │
├─────────────────────────────────────────────┤
│                                             │
│  ┌──────────┐   UDP 广播   ┌──────────┐    │
│  │  客户端A  │◄────────────►│  客户端B  │    │
│  │ (房主/    │              │ (加入者)  │    │
│  │  玩家0)   │              │ (玩家1)  │    │
│  └────┬─────┘              └────┬─────┘    │
│       │                         │           │
│       │       TCP 连接          │           │
│       └──────────┬──────────────┘           │
│                  │                          │
│           ┌──────┴──────┐                   │
│           │  游戏主机    │                   │
│           │  (消息转发)  │                   │
│           └─────────────┘                   │
│                                             │
└─────────────────────────────────────────────┘
```

### 关键技术选型

| 组件 | 技术方案 | 说明 |
|------|---------|------|
| 网络通信 | Winsock2 TCP | 可靠传输，消息驱动 |
| 房间发现 | UDP 广播 | 2 秒内自动发现局域网房间 |
| 并发模型 | 多线程 | accept 线程 + 每客户端独立线程 + 接收线程 |
| 线程同步 | mutex + condition_variable | 生产者-消费者消息队列 |
| 编译环境 | Dev-C++ (MinGW64 g++) | C++11 标准，零外部依赖 |

### 消息协议

采用文本行协议，以 `\n` 分隔，`|` 分字段：

```
JOIN|玩家名          → 加入房间
DD_DISCOVER          → UDP 广播发现房间
DD_ROOM|id|name|port|count|max → 房间信息响应
START|玩家索引        → 游戏开始
CARDS|牌ID列表        → 发送手牌
CALL_TURN|当前玩家    → 叫地主轮次
CALL_RESULT|玩家|分数 → 叫地主结果
LANDLORD|地主|底牌    → 确定地主
TURN|当前玩家         → 出牌轮次
PLAY|PASS|玩家        → 跳过
PLAY|CARDS|玩家|牌    → 出牌
WIN|获胜玩家          → 游戏结束
```

## 使用指南

### 编译

```bash
g++ -std=c++11 -O2 -o doudizhu.exe doudizhu.cpp -lws2_32 -static-libgcc -static-libstdc++
```

或在 Dev-C++ 中直接编译。

### 开局

1. **电脑 A** 运行程序 → 输入名字 → 选择「创建房间」→ 输入房间名
2. **电脑 B、C** 运行程序 → 输入名字 → 选择「自动搜索并加入房间」→ 选择房间编号
3. 三人到齐后，房主输入 `/start` 开始游戏

### 操作

- **叫地主** — 输入 `1`、`2`、`3`（叫分）或 `0`（不叫）
- **出牌** — 输入手牌编号（逗号分隔），如 `0,1,2`
- **跳过** — 输入 `pass`（非自由出牌时可用）
