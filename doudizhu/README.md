# 局域网联机斗地主（C++）

一个基于局域网的三人斗地主游戏，每台电脑运行同一个程序，既可以创建房间（作为服务器），也可以加入房间（作为客户端）。

## 特性

- **P2P 架构**：每台电脑都是服务器，房主创建房间后自动成为主机
- **UDP 广播发现**：局域网内自动搜索可用房间
- **TCP 通信**：稳定的游戏数据传输
- **完整游戏流程**：发牌 → 叫地主 → 出牌 → 胜负判定
- **牌型支持**：单张、对子、三张、三带一/二、顺子、连对、飞机、炸弹、王炸等
- **玩家名称**：开局输入名字，游戏内显示玩家名而非编号
- **输入校验**：非法输入自动提示重新输入

## 编译（Dev-C++ / MinGW64）

### 方式一：批处理

双击运行 `compile.bat`，自动编译生成 `doudizhu.exe`。

### 方式二：命令行

```bat
g++ -std=c++11 -O2 -o doudizhu.exe doudizhu.cpp -lws2_32 -static-libgcc -static-libstdc++
```

### 方式三：Dev-C++

1. 打开 `doudizhu.cpp`
2. 工具 → 编译选项 → 链接器命令行中添加 `-lws2_32`
3. 编译运行

## 使用方法

1. **房主**：运行程序 → 输入名字 → 选择「创建房间」→ 输入房间名 → 等待玩家加入
2. **其他玩家**：运行程序 → 输入名字 → 选择「加入房间」→ 从列表中选择房间
3. **开始游戏**：房主输入 `/start` 开始
4. **叫地主**：按提示输入 `y` 或 `n`
5. **出牌**：输入手牌编号（空格分隔），如 `1 3 5 7`，或输入 `pass` 不出

## 游戏内指令

| 指令 | 说明 |
|------|------|
| `/start` | 房主开始游戏（需 3 人） |
| `/players` | 查看当前玩家列表 |
| `/help` | 查看帮助 |
| `/leave` | 离开房间 |
| `pass` | 不出牌 |
| `1 3 5` | 出第 1、3、5 张牌 |

## 常见问题

- **发现不到房间**：确认在同一局域网，且 Windows 防火墙允许 UDP(37020) 与 TCP 通信
- **编译报错 `ws2_32`**：确保链接了 `-lws2_32` 库
- **连接超时**：检查防火墙设置或尝试关闭后重新创建房间

## 技术架构

- 语言：C++11
- 网络：Winsock2（UDP 广播 + TCP）
- 线程：`std::thread` + `std::mutex` + `std::condition_variable`
- 编译器：MinGW64 g++（兼容 Dev-C++）
